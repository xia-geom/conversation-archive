# Conversation Archive

**Turn useful parts of your ChatGPT and Claude conversations into one organized Markdown file—with original quotations.**

Keep decisions, project notes, reflections, and corrections easy to find. You or an authorized AI agent write the entries; the toolkit preserves evidence, tracks review progress, and checks proposed edits.

[Try the demo](#try-it-without-private-data-or-a-model) · [Getting started](docs/getting-started.md) · [Read an example](examples/sample-archive.md) · [All guides](docs/README.md)

**Status:** experimental alpha · **Requires:** Python 3.11+ · **Platforms:** macOS and Linux · **License:** [MIT](LICENSE)

## See what you get

The [included example](examples/sample-archive.md) is generated by the demo from invented conversations. A short preview:

> **E0001 — Garden**
>
> The owner reported planting mint.
> Event date: not established by the message timestamp.
>
> “I planted mint. 我今天种了薄荷。”

The full file includes the message ID, export fingerprint, and quotation location. Assistant suggestions stay separate from the person's account. Open the `.md` file in your editor, keep it locally, or choose to supply it to ChatGPT.

## Try it without private data or a model

You need **Git and Python 3.11 or newer**. In a terminal:

```sh
git clone https://github.com/xia-geom/conversation-archive.git
cd conversation-archive
python3 --version
```

Run the demo from that folder. No package installation, API key, or model connection is needed:

<!-- smoke:quickstart:start -->
```sh
python3 -m conversation_archive demo --output data/markdown-demo
```
<!-- smoke:quickstart:end -->

**Open `data/markdown-demo/organized.md` in your text editor.** The command prints its full path and confirms the update passed, the original stayed unchanged, and replay added nothing twice. Review decisions are predetermined; this does not evaluate AI accuracy.

```text
data/markdown-demo/
├── organized.md    ← Start reading here
├── exports/        Invented source conversation
└── .state/         Import records, reviews, and update receipts
```

To try again, use a fresh directory such as `data/markdown-demo-2`. Existing output is preserved. See [troubleshooting](docs/troubleshooting.md) for setup problems.

## How the work is divided

```text
Export → Select conversations → Review and write → Check the diff → Save Markdown
```

**Real records need editorial review.** The toolkit imports ChatGPT and Claude exports, prepares source packets, checks quotations, and refuses stale edits. You or your agent choose what belongs, interpret the evidence, and review the proposed text. Importing alone does not summarize or update your document. Gemini imports and automatic semantic deduplication are not implemented.

For an agent-assisted review, open this repository in your agent and supply your actual paths:

> Read `.agents/skills/organize-markdown/SKILL.md`. Review my selected document at `/absolute/path/organized.md` against the supplied sources. Preserve my edits, original languages, corrections, and uncertainty. Show the proposed Markdown and explain unresolved issues before applying changes. Ask me only about consequential ambiguity.

Keep private files outside Git. Import, checking, and the demo run locally. Cloud-agent access or model processing requires separate transfer authorization; see [privacy](PRIVACY.md). Uploading to ChatGPT remains your choice.
