# Conversation Archive 0.1.2a1 — experimental alpha

Preserve conversation evidence, inspect proposed connections, and keep scoped corrections reusable.

## Available today

ChatGPT/Claude export normalization and source validation; an offline synthetic demo; optional bounded Codex candidate extraction; separate review and legacy reconciliation; relationship organization from supplied candidates; batches of 15 context-rich clarification questions, configurable to 10 or 20.

Start with the README and `AGENTS.md`. Python 3.11+ and macOS/Linux are the supported controller environment. The offline demo needs no model, API key, or dependency installation after cloning. Live model use is separately authorized and requires local Codex setup.

## Boundaries

This alpha is not a fully autonomous knowledge organizer. Automatic semantic discovery, full cross-export incremental identity, a shipped structured-authority migration, and LLM-generated views remain outside this release. The new end-to-end workflow and migration work were explicitly deferred during launch preparation. Existing tests were rerun; no new independent user trial or live-model benchmark is claimed.

Use synthetic data first. Original evidence remains separate from model suggestions and accepted rules. No automatic master promotion, privacy guarantee, hard dollar budget, or objective-truth guarantee is claimed.
